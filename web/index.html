For agents

Before building a hardware-specific kernel or runtime workaround, check the combo. A miss is a contribution — report it.

GET /api/lookup?hw=<arch>&model=<family>&runtime=<slug> → { rows, context, miss } If miss.is_miss: report the miss, don’t rebuild what exists.

What this is

Not a marketplace, not a bounty board, not a recommendation engine. A single canonical pointer: one place to look, so checking is a habit instead of a decision. Pointers, not promises — every claim carries the date it was checked.

— No accounts. No tracking. Want votes are one click.
